## 使用方法

播放地址形如：

```
http://192.168.2.1:4022/udp/239.253.232.77:8000
          └─ 路由器      └─ msd_lite/udpxy 端口   └─ 组播地址
```

需要先在路由器上把组播转成单播（本项目用的是 **msd_lite**，监听 `4022`）。

- `192.168.2.1` 是内网路由器地址，**播放器必须和路由器在同一网段**；如果你的路由器不是这个地址，全局替换一下即可。
- 本列表只依赖**组播**，不需要 IPTV 账号鉴权（直播可以直接看）。

订阅地址：

```
https://raw.githubusercontent.com/fqscfqj/ShandongUnicomIPTV/main/iptv.m3u
```

## 节目单（EPG）

只用一个源，**plsy1**（山东联通本平台数据，162 个台）：

```
x-tvg-url="https://fastly.jsdelivr.net/gh/plsy1/epg@main/e/seven-days.xml.gz"
```

选它是因为它是覆盖这个列表最全的一份：按 `tvg-id` 精确匹配，**覆盖 147 / 164**。

9 个台的 4K 版本在 plsy1 里有**独立的节目单 id**（例如 `193` 山东卫视4K / `2` 山东卫视），节目表与高清版完全一致，所以删掉高清一路不影响节目单。

（另一份常用的 fanmingming `e.xml` 只有 123 个台、对本列表只覆盖 86 个，所以没有采用。plsy1 的 GitHub 原地址是 `https://raw.githubusercontent.com/plsy1/epg/main/e/seven-days.xml.gz`，和上面的 jsdelivr 是同一份数据，哪个通就用哪个。）

剩下 **17 路没有节目单**：CCTV16 奥林匹克、爱上4K、四川卫视4K、海南卫视、山东海洋频道、重温经典影视、东营综合、东营公共、胜利综合、广饶新闻、中国交通、海看演艺、山东购物、环球购物、优购物、央广购物、山东经济广播 —— plsy1 里确实没有这些台的数据。

## 已知问题

- 9 个卫视现在只有 4K HEVC 一路，**播放器需要支持 HEVC/H.265 且带宽足够**（每路约 20–27 Mbps）；否则这些台会看不了。想恢复高清一路，从 git 历史里取回对应条目即可。
- `爱体育`（`239.253.232.131`，剧场影院）与 `IHOT爱体育`（`239.253.232.109`，付费频道）是同一个台的两路源（EPG id 都是 `169`、都是 1080p），按分辨率并列最高，暂时两路都留着。
