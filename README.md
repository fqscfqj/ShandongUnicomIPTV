## 使用方法

播放地址形如：

```
http://192.168.2.1:4022/udp/239.253.232.77:8000
          └─ 路由器      └─ msd_lite/udpxy 端口   └─ 组播地址
```

需要先在路由器上把组播转成单播（本项目用的是 **msd_lite**，监听 `4022`）。

- `192.168.2.1` 是内网路由器地址，**播放器必须和路由器在同一网段**；如果你的路由器不是这个地址，全局替换一下即可。
- 本列表只依赖**组播**，不需要 IPTV 账号鉴权（直播可以直接看）。

订阅地址：

```
https://raw.githubusercontent.com/fqscfqj/ShandongUnicomIPTV/main/iptv.m3u
```
